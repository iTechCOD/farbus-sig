# Changelog — Farbus SIG

## E2 — revisión final de Entrega 2 (21-11-2026)

- Se mantiene el caso Farbus de la Entrega 1 y la distinción entre programación y ejecución.
- Se materializa modelo ER 3FN con 15 tablas, FK, CHECK y triggers.
- Se incorporan `db/schema.sql` y `db/seed.sql` con demostración sintética identificada.
- Se añaden cinco consultas SQL independientes con resultados CSV auditables.
- Se implementan catorce pruebas automatizadas de reglas de negocio e integridad.
- Se documenta automatización homóloga a n8n con script de alertas operativas, reproducible.
- Se actualizan diagramas BPMN TO-BE y ER con archivos fuente editables.
- Se incorpora presentación y nuevo informe Word/PDF, más documentación `.md`.
- Cambio explícito de arquitectura tentativa: PostgreSQL/FastAPI planificados en E1 → prototipo SQL local SQLite/Python en E2. La interfaz web y autenticación quedan **pendientes**, no se atribuyen como funciones implementadas.
- No se publicaron resultados ni datos operativos ficticios atribuidos a la empresa; la evidencia E1 se mantiene en el repositorio original.

- Se reforzaron controles de capacidad, actualización de programación y consistencia de preliquidaciones, y se confirmó la excepción docente para modalidad individual.
